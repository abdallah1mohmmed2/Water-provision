# فلاتر الفترة لتقارير PDF فوق بطاقات الأطراف — 2026-11-28

## الطلب
في جميع أنواع المنظومات، إضافة فلتر «من تاريخ / إلى تاريخ» في قائمة PDF التي تظهر فوق بطاقات المستفيد والعامل والشريك، وربط نفس الفترة بكل التقارير التي تعرضها القائمة.

## التنفيذ
- قائمة PDF تعرض حقلي تاريخ اختياريين (من/إلى) قبل خيارات التقرير.
- يمكن اختيار تاريخ واحد أو الاثنين؛ ترك الحقول فارغة يعني كامل الفترة.
- زر «مسح الفترة» يعيدها إلى كامل الفترة.
- إذا تم اختيار التاريخين وكان تاريخ البداية بعد النهاية، يمنع فتح التقرير ويعرض تنبيهاً.
- الفترة نفسها تمر إلى التقارير: السقايات، كشف الحساب، تقرير الديزل (المسلّم/المستهلك/المتبقي)، الحركات النقدية، وتقارير النوع الثالث الشمسية والديزل.
- الضغط العادي للمعاينة والضغط المطوّل للمشاركة يستخدمان نفس الفترة.
- تم توحيد callback قائمة التقارير لتستقبل التقرير والفترة، وتحديث نقطة PDF في صفحة التفاصيل لتستخدم الفلتر نفسه.
