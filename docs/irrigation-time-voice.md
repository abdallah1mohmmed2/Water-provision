# نطق وقت السقاية في الفورم السريع

- بعد اختيار وقت البداية، ينطق التطبيق الوقت ثم ينتقل مباشرة لاختيار النهاية.
- بعد اختيار وقت النهاية، ينطق وقت النهاية.
- لا ينطق أثناء الكتابة اليدوية أو أثناء تعديل كل رقم.
- يحترم إعداد الصوت العام المحفوظ محليًا.
- التنفيذ الحالي يستخدم محرك Android TTS باللغة العربية كبديل مؤقت؛ لا اتصال بالإنترنت مطلوب، ولا يؤثر فشل النطق على الفورم أو الحفظ.
- التغيير محصور في اختيار الوقت داخل الفورم السريع؛ لا تغييرات محاسبية أو قاعدة بيانات.

## التنفيذ الحالي
- `lib/services/irrigation_time_voice_service.dart`: صياغة الإعلان واستدعاء قناة Android. لا يوجد timeout؛ Android يعيد الرد بعد إضافة الكلام للطابور.
- `MainActivity.kt`: محرك النطق العربي مع إضافة المقاطع إلى طابور الصوت دون تعطيل الفورم.
- `test/irrigation_time_voice_service_test.dart`: صياغة البداية والنهاية، منتصف الليل/الظهر، والدقائق.

## ملفات MP3 الأصلية - حالة الدمج
- الحزمة الأصلية مفحوصة: 76 ملفًا، ZIP حجمه 829,932 bytes، والملفات الصوتية مجتمعة 1,037,952 bytes.
- تحقق من الاكتمال: `n_1.mp3`.. `n_59.mp3`، `h_1.mp3`.. `h_12.mp3`، و`from.mp3`, `to.mp3`, `and.mp3`, `am.mp3`, `pm.mp3`؛ لا ملفات مفقودة أو غير متوقعة.
- تم تجهيز نسخة ZIP مرتبة حسب مسار المستودع: `assets/audio/irrigation_time/`، مع الحفاظ على ملفات MP3 الأصلية دون تغيير. النسخة الجاهزة موجودة كمرفق في محادثة العمل باسم `irrigation_audio_repository_payload.zip`.
- **لم يتم رفع الملفات الثنائية إلى GitHub ولم يتم توصيل MP3 playback بالكود بعد.** ما يزال TTS بديلًا مؤقتًا.
- العائق الحالي: GitHub connector المستخدم في هذه الجلسة يدعم تحرير ملفات النصوص وإنشاء blobs نصية، لكنه لا يوفّر رفعًا مباشرًا لملفات binary من ZIP؛ لم تُنشأ commit تشير إلى assets غير موجودة.
- الخطوات المتبقية: إدخال payload إلى المستودع دون تغيير أسماء الأصول، إضافة تعريف Flutter assets، دمج مشغل الصوت بالتسلسل داخل اختيار الوقت للفورم السريع فقط، إبقاء التشغيل غير حاجب وTTS fallback، اختبار بداية/نهاية و12/24 ساعة والظهر/منتصف الليل والدقيقة صفر والدقائق الأخرى وإعداد الصوت، ثم CI/build وتحديث التوثيق.
