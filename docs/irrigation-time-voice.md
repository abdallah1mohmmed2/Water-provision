# نطق وقت السقاية في الفورم السريع

- بعد اختيار وقت البداية، ينطق التطبيق الوقت ثم ينتقل مباشرة لاختيار النهاية.
- بعد اختيار وقت النهاية، ينطق وقت النهاية.
- لا ينطق أثناء الكتابة اليدوية أو أثناء تعديل كل رقم.
- يحترم إعداد الصوت العام المحفوظ محليًا.
- التنفيذ الحالي يستخدم محرك Android TTS باللغة العربية كبديل مؤقت؛ لا اتصال بالإنترنت مطلوب، ولا يؤثر فشل النطق على الفورم أو الحفظ.
- التغيير محصور في اختيار الوقت داخل الفورم السريع؛ لا تغييرات محاسبية أو قاعدة بيانات.

## التنفيذ الحالي
- `lib/services/irrigation_time_voice_service.dart`: صياغة الإعلان واستدعاء قناة Android. لا يوجد timeout؛ Android يعيد الرد بعد إضافة الكلام للطابور.
- `MainActivity.kt`: محرك النطق العربي مع إضافة المقاطع إلى طابور الصوت دون تعطيل الفورم.
- `test/irrigation_time_voice_service_test.dart`: صياغة البداية والنهاية، منتصف الليل/الظهر، والدقائق.

## المطلوب لإتمام الدمج الفعلي
1. إدخال الـ76 ملفًا من الحزمة المجهزة إلى `assets/audio/irrigation_time/` بأسمائها الأصلية.
2. إضافة تعريف Flutter assets في `pubspec.yaml`.
3. اختيار مشغل مناسب لتشغيل المقاطع بالتسلسل، مع enqueue أو queue خفيف لا يعطل واجهة الفورم ولا يوقف الانتقال/الحفظ.
4. صياغة ترتيب الصوت بدقة حسب clips: إعلان بداية/نهاية، الساعة، رقم الساعة، الدقائق (تجاوزها عند صفر)، صباح/مساء؛ التحقق من الاستماع الفعلي للclips قبل الجزم بلفظها.
5. الإبقاء على TTS كـ fallback إذا تعذر تحميل/تشغيل المقاطع.
6. الاختبارات: البداية/النهاية، 12/24، منتصف الليل/الظهر، الدقيقة 0، إعداد الصوت، وعدم blocking؛ ثم Analyze + APK build ورفع النتائج هنا.
