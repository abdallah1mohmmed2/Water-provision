# تقرير المديونيات — فلاتر الشهر والبحث

التاريخ: 2026-11-03  
الفرع: `experiment/main-based-2026-11-02`

## ما تم تغييره

- إضافة اختيار شهر في شاشة تقرير المديونيات، مع التنقل للشهر السابق/التالي واختيار شهر من التقويم.
- الشهر المختار يعرض الرصيد القائم لكل مستفيد حتى نهاية ذلك الشهر، وليس فقط الديون التي أُنشئت خلال الشهر. بذلك تنتقل المديونية غير المسددة من شهر إلى الأشهر التالية.
- لقطة الرصيد الشهرية تحسب: الرصيد الافتتاحي والمرحل + المديونيات اليدوية المنشورة + السقايات غير الملغاة + سلف الديزل اليدوية، ثم تخصم دفعات المستفيد المنشورة، وتخصم تسليم الديزل إذا كان إعداد المحطة يعامله رصيداً مالياً.
- إصلاح بطاقات الإجماليات وعدد الحسابات لتتبع نتائج الفلاتر الحالية (بحث الاسم/الهاتف، عليه، له، متوازن) بدلاً من إجمالي القائمة الكاملة.
- PDF يأخذ الشهر المختار ونتائج الفلاتر نفسها. كما أصبح تمرير قائمة فارغة صراحةً إلى مولد PDF يعني طباعة تقرير فارغ مطابق للفلاتر، لا إعادة جلب كل البيانات.
- إضافة رقم الهاتف إلى صفوف تقرير المديونيات لدعم البحث والطباعة.

## حماية البيانات والمنطق المحاسبي

- التغيير قراءة فقط؛ لا ينشئ أو يعدل قيوداً أو سندات قبض أو أرصدة أو بيانات SQLite.
- الرصيد الشهري تاريخي حتى نهاية الشهر المحدد. لا تستخدم الفترة لتصفية السقايات وحدها مع تجاهل الدفعات اللاحقة داخل نفس الشهر.
- لم يتم تغيير دلالة الرصيد: الموجب «عليه»، والسالب «له».

## التحقق

- يلزم انتظار GitHub Actions على آخر commit للتحقق من `flutter analyze` و`flutter test` وبناء APK.
- لم يُعلن نجاح الاختبارات أو بناء APK عند إنشاء هذا التوثيق.
- لا دمج إلى `main`.
