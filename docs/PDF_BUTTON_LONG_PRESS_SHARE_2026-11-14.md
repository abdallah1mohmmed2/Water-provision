# Long-press PDF buttons to share directly

Date: 2026-11-14
Branch: `feature/firebase-station-foundation`, with `main` unchanged.

## User-visible behavior
- Ordinary tap on each existing PDF button retains the existing PDF preview.
- Long press of a PDF button skips the preview and opens the same editable
  filename dialog, then invokes Android's PDF share sheet. If the dialog is
  cancelled, no share is attempted.
- Buttons remain in their existing positions with the same theme, text and
  enabled/disabled conditions. No new toolbar buttons were added.
- Each report's filters, party ID, period and data generation are the same
  as the pre-existing onPressed callback.
- Existing explicit print/share controls inside the PDF preview are untouched;
  a normal tap of PDF still supports save/print from the viewer.

## Implementation
- `ReportPdfPreviewService.shareOnLongPress` executes the existing report
  generation inside a Dart async zone. When that report reaches
  `ReportPdfPreviewService.open`, it reuses the generated PDF bytes,
  prompts for a filename and shares instead of pushing a preview route.
  A zone avoids global mutable flags and cross-report leakage when actions
  overlap. It is intentionally not a toggle stored in application settings.
- `ReportPdfLongPress` wraps existing PDF button widgets. Short taps remain
  under the button's original onPressed handler; hold invokes only the
  new callback. Native tooltips are removed from *wrapped icon-only buttons*
  to avoid competing long-press recognizers; accessible semantics describe
  the shortcut.
- All operations are read-only on report data. No DB migration or changes
  to report totals, layout, financial entries, and generated bytes.
- Errors during long-press export produce a snackbar, not silent failure.
- The existing `Printing.sharePdf` path and filename sanitation are reused.

## Coverage
- Report center's generated PDF actions for all 28 registered reports,
  details of worker, partner, beneficiary and irrigation,
  receipt actions, ledger, debts, comparisons, finance, income, diesel,
  expenses, individual worker PDFs and the invoices viewer entry points.
- General accounts PDF and monthly reconciliation PDF.
