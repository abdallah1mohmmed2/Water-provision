# Unified PDF report preview migration — 2026-11-14

Branch: `feature/firebase-station-foundation`. `main` is untouched.

## Design and invariants
- All PDF bytes are generated by existing functions. No database writes,
  accounting calculations, PDF table layout, typography or theme are changed.
- The reusable `ReportPdfPreviewService.open()` opens the existing
  `printing` package's `PdfPreview` UI from the root Navigator, supporting
  pinch zoom, scrolling and multi-page navigation.
- App-bar actions explicitly **print/save** and **share**. The existing
  file-name dialog is shown only if an export action is selected (not on
  entry into the preview); cancelling leaves the preview open.
- Print uses `Printing.layoutPdf`; if native printing throws,
  `Printing.sharePdf` is offered using exactly the same bytes/name.
  Share uses `Printing.sharePdf` directly.
- An empty PDF and a missing Navigator fail clearly rather than opening a
  blank document or silently choosing a different output path.
- The generated PDF is held only in memory for the lifetime of the preview;
  it is never re-rendered or re-queried on save/share.
- Gradual rollout: at most nine report keys per migration commit.
