# Unified PDF report preview migration — 2026-11-14

Branch: `feature/firebase-station-foundation`. `main` is untouched.

## Design and invariants
- All PDF bytes are generated by the **existing** reporting functions;
  no database schema, record, accounting calculation, PDF columns,
  totals, colors, fonts or saved settings are modified.
- A single `ReportPdfPreviewService.open()` provides the same Flutter
  `PdfPreview` used previously for invoice viewing: zoom, scroll and
  multi-page navigation.
- The toolbar allows **Print / Save as PDF** or **Share PDF**. The existing
  editable file-name dialog appears after choosing either export action,
  not before displaying the preview. Cancellation returns to the preview.
- Android's native print/save workflow remains `Printing.layoutPdf`, and
  failed native printing still falls back to sharing the same immutable
  PDF bytes with the same chosen name.
- Sharing uses `Printing.sharePdf`. Saving does not rewrite/modify the
  generated bytes. No local file is overwritten by the preview.
- Empty PDFs or a missing navigator raise a clear error; already-generated
  PDFs are not reloaded from the database just to print/share.
