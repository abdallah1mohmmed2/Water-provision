# عرض رصيد الديزل فوق بطاقات النوع الثالث — 2026-11-28

## المطلوب
عرض رصيد الديزل المرتبط بكل مستفيد أو عامل أو شريك مباشرة فوق بطاقته في النوع الثالث، بنفس شكل بطاقة رصيد الديزل في منظومة الديزل.

## التعديل
- `PartyDieselBalance.loadRows` أصبح يحمل أرصدة الأطراف في نوع المنظومة `diesel` و`equivalent_hybrid`.
- لا يتم تحميل أو عرض رصيد الديزل في `solar` فقط.
- تستخدم البطاقات مكون `PartyDieselBalance` الحالي، مع نفس تنسيق «له / عليه» باللترات وألوان الرصيد.
- لا تغييرات في دفتر الحركات أو الحسابات أو التقارير؛ القراءة من سجل الديزل الحالي فقط.

## الاختبار المضاف
في `test/diesel_delivery_test.dart`:
- اختبار أرصدة المستفيد والعامل والشريك في النوع الثالث بعد تسجيل تسليم 9 لترات لكل طرف.
- تحقق من إخفاء الرصيد في النظام الشمسي.

## حالة CI
لم يتم اعتماد نجاح البناء/الاختبارات قبل انتهاء GitHub Actions على commit التعديل.
