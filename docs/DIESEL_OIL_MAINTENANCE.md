# متابعة تغيير زيت منظومة الديزل

- المدخل: الإعدادات ← المنظومة والتسعير ← موعد تغيير الزيت وتكلفته؛ وبطاقة في الرئيسية للديزل فقط.
- المدير يضبط عدد ساعات التغيير والتنبيه قبل الاستحقاق وساعات مستهلكة افتتاحية عند التفعيل الأول. لا يصفّر تعديل الإعدادات العدّاد.
- العدّاد لكل محطة، من مدد بداية/نهاية كل سقاية ديزل مرحّلة بعد بدء الدورة، للمستفيد والعامل والشريك. حفظ تسقية3ساعات ينقص120إلى117فورًا، حتى لو أدخل المستخدم وقتها بتاريخ سابق أو نهاية لاحقة لساعة الجهاز. الحجز/المجدول وغير المرحّل والملغى والشمسية لا تُحسب. لا يستخدم دقائق الفوترة أو خصم الغيوم. تعديل/إلغاء سقاية في الدورة يعيد الحساب؛ لا تكرار للخصم عند إعادة القراءة أو التشغيل.
- الدورة الجديدة تحفظ آخر معرّف سقاية للمحطة عند الإعداد الأول أو تأكيد تغيير الزيت، لتستبعد سجلات الدورة السابقة دون تغييرها. الدورات المحفوظة القديمة بلا هذا الحقل تحتفظ بحساب الفترات التاريخية مع احتساب التسقيات الجديدة المسجلة بعد بداية الدورة كاملة؛ لا تصفير تلقائي أو ترحيل قيود.
- التنبيه داخل التطبيق: تحديث بعد نجاح حفظ/تعديل/إلغاء السقاية، وعند فتح الرئيسية والاستئناف وكل30ثانية. بعد بلوغ حد التحذير يتكرر التنبيه مع تغيّر الساعات المستهلكة، ويستمر عند الصفر وبعده؛ لا تكرار بسبب فحص المؤقت وحده، ولا عودة للبداية إلا بتأكيد تغيير الزيت. لا إشعار مضمون عندما يكون التطبيق مغلقًا.
- المدير والمحاسب يسجلان التكلفة وطريقة الدفع والصندوق. تأكيد «تم تغيير الزيت» ينشئ مصروف oil عاديًا على الحساب 5020، ينقص الصندوق ويؤثر في صافي الربح مرة واحدة، ويبدأ دورة جديدة في نفس معاملة SQLite. لا تغيير في إيراد السقاية نفسه.
- فشل التحقق/الصلاحيات/إغلاق الفترة/تكرار الإرسال يراجع كامل المعاملة. رمز الدورة يمنع إرسال شاشتين لنفس الدورة، ومعرّف الطلب يمنع إعادة إرسال عملية سبق تسجيلها ولو ألغيت لاحقًا.
- الإلغاء من السجل أو شاشة المصروفات يستخدم cancelExpense: سبب إلزامي وقيد عكسي ورد الصندوق دون حذف الأصل. العدّاد يعود لآخر تغيير غير ملغى؛ إلغاء سجل أقدم لا يلغي الدورة الأحدث.
- التخزين المحلي: إعدادات وسجل روابط المصروفات JSON لكل محطة في settings. هذه البيانات ضمن نسخة SQLite الاحتياطية، لكنها لا تزامن بين الأجهزة حاليًا. expense وحده يستخدم بروتوكول Outbox/الخادم/Inbox القائم؛ لا إرسال مستقل للقيود أو أثر الصندوق. مزامنة الصيانة نفسها مرحلة لاحقة.
- لا حساب تلقائي لسعر الزيت وفق الساعات: تدخل التكلفة الفعلية عند كل تغيير. لا كمية زيت/مخزون جديد.
