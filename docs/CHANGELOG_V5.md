# الإصدار V5 - مطابقة المواصفات

هذه الدورة ليست إعادة بناء للمشروع. تم تعديل نفس مصدر V4.

## إصلاحات منطقية

- تطبيق إعداد `partial_hour` فعليًا على الأنظمة الثلاثة: إذا كان مفعّلًا تحسب الدقائق كجزء من الساعة، وإذا كان معطلًا تُحسب الساعة الجزئية كساعة كاملة.
- إضافة حارس الفترة المحاسبية `_assertPeriodOpen` إلى العمليات المالية الأساسية، بحيث لا تُسجل حركة جديدة داخل فترة مغلقة.
- إضافة اختبارات لحساب الساعة الجزئية، منتصف الليل، خصم الغيم، الأنظمة الثلاثة، و`له/عليه`.
- إزالة تكرار حالة `queue_bookings` في التقرير.

## API/server

- تعزيز رمز المستفيد إلى رقم عشوائي آمن من 6 أرقام، مع حد لمحاولات التحقق.
- إضافة قيود محاسبية إلى عمليات API للدفعات والمصروفات.
- إكمال إنهاء جلسة API بحيث يسجل السقاية الفعلية والمدة والتكلفة واستهلاك الديزل وتحديث الحجز/الطابور.
- إضافة استعادة قاعدة بيانات الخادم من ملف SQLite مشفر بالنقل عبر base64 بعد فحص البنية، مع إنشاء نسخة قبل الاستعادة.
- تصحيح إرجاع معرف الدفعة/المصروف بعد إنشاء القيد.
- تضمين رصيد سلفة الديزل والرصيد المالي لتسليم الديزل في كشف المستفيد حسب إعداد النظام.
