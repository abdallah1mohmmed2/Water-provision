# V15.x Cloud Deduction Update

- خصم الغيم أصبح داخل بطاقة «بيانات التشغيل» في شاشة «سقاية جديدة».
- يمكن إضافة فترة غيم واحدة أو عدة فترات، لكل فترة وقت «من» و«إلى».
- تمنع الواجهة والطبقة المحاسبية الفترات خارج مدة السقاية والتداخل وتجاوز إجمالي مدة السقي.
- أضيف جدول `cloud_periods` مرتبط مباشرة بالسقاية مع `ON DELETE CASCADE`.
- مجموع دقائق الغيم يحدد `cloud_minutes`، والدقائق القابلة للمحاسبة = مدة السقي - مجموع الغيم.
- لا يطبق خصم الغيم إلا على المنظومة الشمسية.
