## الهدف
إنشاء تطبيق مستقل للعمال ضمن منظومة Water-provision، مع الاستفادة من البنية الحالية دون نسخ القيود المحاسبية أو إنشاء مصادر بيانات مالية مكررة.

## نطاق التطبيق المقترح

### شاشات العامل
1. الرئيسية: ملخص العمل والمستحقات والمدفوعات وآخر العمليات.
2. سجل السقايات: السقايات المرتبطة بالعامل، تفاصيل الوقت والأجر، البحث والتصفية.
3. الحساب المالي: كشف حساب العامل، الرصيد الافتتاحي والحركات والرصيد النهائي.
4. المستحقات والمدفوعات: تفاصيل الأجور وسندات الصرف وملفات PDF.
5. جدول العمل والدور والتكليفات، وفق الصلاحيات الممنوحة.
6. الإشعارات.
7. الشكاوى والبلاغات ومتابعة رد الإدارة.
8. الملف الشخصي والإعدادات.
9. التقارير والتصدير PDF.
10. طلبات الإجازة والغياب والتواصل مع الإدارة، إذا اعتمدت ضمن نطاق التنفيذ.

### أنظمة الأجر
- أجر ثابت: شهري أو أسبوعي أو يومي.
- أجر بالساعة مع احتساب الدقائق وفق قواعد النظام.
- أجر بالنسبة، مع تحديد أساس الاحتساب صراحة.
- دعم النظام المختلط (ثابت + ساعة أو نسبة) عند اعتماده.
- حفظ تاريخ سريان تغييرات الأجر حتى لا يعاد احتساب الفترات السابقة بأثر رجعي.
- لا يسمح للعامل بتعديل نوع أجره أو قيمته أو اعتماد مستحقاته لنفسه.

### الصلاحيات
- صلاحيات مستقلة لكل عامل، مع أدوار جاهزة قابلة للتخصيص.
- فصل العرض عن الإضافة والتعديل والحذف والاعتماد.
- مجموعات الصلاحيات تشمل السقايات والمستفيدين والحسابات وإدارة العمل والتقارير.
- لا يحصل المشرف تلقائياً على صلاحيات مالية.
- لا يمكن للعامل منح نفسه صلاحيات أو الاطلاع على حسابات العمال الآخرين دون تفويض صريح.
- تسجيل العمليات الحساسة في سجل تدقيق يوضح الفاعل والتوقيت والتغيير.

## ضوابط البيانات والمحاسبة
- قراءة الحركات المالية من سجلات منظومة المحطة الأصلية.
- عدم إنشاء قيود أو أرصدة مكررة لمجرد عرضها في تطبيق العامل.
- العامل يرى بياناته وسقاياته ومستحقاته فقط افتراضياً.
- تبقى التعديلات المالية والوظيفية الحساسة بيد الإدارة والمخولين.
- يجب مراجعة آلية احتساب أجور العمال الحالية في الشيفرة وقاعدة البيانات قبل تنفيذ أي تعديل.

## خطة التنفيذ
1. فحص الفرع المصدر والبنية الحالية للعمال والأجور والحسابات والمصادقة والصلاحيات.
2. توثيق النتائج وخطة الربط قبل تعديل منطق البيانات.
3. تنفيذ واجهات العامل وتسجيل الدخول والصلاحيات.
4. ربط السقايات وكشف الحساب والمدفوعات دون تكرار محاسبي.
5. تنفيذ إعدادات الأجور وتاريخ سريانها بعد التحقق من قواعد المحاسبة الحالية.
6. تنفيذ الإشعارات والبلاغات والتقارير.
7. تشغيل التحليل والاختبارات والبناء وإتاحة APK للتجربة قبل أي اعتماد.
