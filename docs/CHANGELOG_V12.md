# V12

## Acceptance focus

هذه النسخة مخصصة لأربع طبقات قبول قبل أي حديث عن APK:

1. **نوع المنظومة المركزي**
   - `settings.system_type` هو المصدر المركزي.
   - المضخة المحددة من `selected_pump_id` هي المضخة الوحيدة المستخدمة.
   - عند تغيير نوع المنظومة تتم مزامنة نوع المضخة المحددة.
   - تسجيل السقاية وبدء الجلسة يتحققان من النوع والمضخة من طبقة البيانات/المحاسبة، وليس من قيمة واجهة قابلة للتلاعب.

2. **إخفاء الديزل في المنظومة الشمسية**
   - إزالة قائمة الديزل من التنقل عند النظام الشمسي.
   - عدم عرض بطاقات/حقول/إعدادات الديزل في الشاشة المناسبة.
   - منع صفحة الديزل وتقرير مخزون الديزل عندما يكون النظام شمسيًا.
   - عدم قراءة مخزون الديزل عند بدء جلسة شمسية.

3. **PDF والعربية**
   - استخدام خطي Noto Naskh Arabic صراحةً للعناوين والخلايا والفلاتر والتذييل.
   - تعريف أعمدة عربية لكل تقرير بدل الاعتماد على أول مفاتيح صف عشوائيًا.
   - استخدام A4 أفقي للتقارير الجدولية.
   - منع إخراج القيم الداخلية لبعض الحالات/الأنواع كما هي.
   - أضيف اختبار PDF مستقل يثبت وجود المحارف العربية في الخطين وأن PDF تجريبيًا بهما ينتج نصًا عربيًا قابلًا للاستخراج، مع رفض `####`.

4. **دورة النسخ الاحتياطي والاستعادة**
   - checkpoint لقاعدة SQLite قبل النسخ.
   - إغلاق الاتصال قبل نسخ ملف قاعدة البيانات.
   - التحقق من النسخة قبل تسجيلها.
   - إعادة فتح الاتصال صراحةً قبل كتابة سجل النسخ.
   - الاستعادة تتحقق من المصدر، تحفظ نسخة rollback، تستبدل القاعدة، تعيد فتحها، وتتحقق منها قبل إعلان النجاح.
   - عند الفشل تتم محاولة rollback وإعادة فتح قاعدة البيانات السابقة.
