# تطبيق الشركاء — مواصفات التنفيذ المرحلي

## القرار المعماري
- اسم فرع التطوير: `feature/partner-in-app`.
- الفرع الأب: `feature/beneficiary-in-app-login`، وتم إنشاء الفرع من رأسه عند البدء.
- التجربة الحالية على قاعدة SQLite الرئيسية نفسها على الجهاز نفسه عبر `AppDatabase.instance`.
- لا تُنشأ قاعدة ثانية ولا تُنسخ القيود أو الحركات المحاسبية.
- لاحقًا تُستبدل طبقة الوصول المحلية بمستودعات API مع إبقاء واجهات التطبيق ومنطق العرض.
- يمنع الدمج إلى `main` أو إلى فرع المستفيد إلا بطلب صريح.

## الصلاحيات المتفق عليها
- يطّلع الشريك على جميع السقايات والفواتير التشغيلية في المحطة، لا العمليات المرتبطة بحصته فقط.
- تشمل المشاهدة تفاصيل الفاتورة والبحث والتصفية وتقارير PDF.
- الشريك لا يستطيع إنشاء السقايات أو تعديلها أو حذفها أو تغيير الفواتير.
- الحساب والأرباح والتوزيعات والتسويات وكشف الحساب الشخصي تخص الشريك المسجل فقط.
- لا تظهر الحسابات الشخصية أو كشوف حسابات الشركاء الآخرين.

## الشاشات المستهدفة
1. تسجيل دخول الشريك باسم مستخدم وكلمة مرور ينشئهما مدير المحطة.
2. الرئيسية: ملخص الاستحقاق والرصيد والمدفوعات ومؤشرات المحطة.
3. حركة المحطة: جميع السقايات والفواتير مع البحث والتصفية والتفاصيل.
4. حسابي المالي: كشف حركات الشريك ورصيده الشخصي.
5. الأرباح والتوزيعات والتسويات.
6. التقارير ومستندات PDF.
7. الملف الشخصي وتغيير كلمة المرور.
8. الإشعارات والتواصل والشكاوى (مراحل لاحقة).

## التنفيذ المرحلي
- المرحلة الأولى: مصادقة محلية مستقلة للشريك، شاشة دخول، الرئيسية، حركة المحطة للقراءة فقط، وكشف حساب الشريك.
- المرحلة الثانية: تفاصيل الأرباح والتوزيعات والتسويات والتقارير.
- المرحلة الثالثة: الإشعارات والتواصل والشكاوى وتحسينات الملف الشخصي.
- المرحلة الرابعة: تجهيز طبقة مستودعات قابلة للاستبدال بـ API ثم تجربة الربط الخارجي.

## قاعدة البيانات
- الإصدار السابق: 22.
- الإصدار الجديد في هذا الفرع: 23.
- الإضافة: `partner_credentials` و`partner_sessions` فقط.
- لا تُعدّل سجلات المحطة التشغيلية أو قيود الأستاذ أو أرصدة الشركاء الحالية.
- بيانات اعتماد الشريك منفصلة عن بيانات المستفيد، وكلمة المرور مخزنة بصيغة Argon2id والجلسة برمز عشوائي مع بصمة SHA-256.

## التحقق المطلوب
- اختبارات الدخول الصحيح والخاطئ والحساب المعطل وانتهاء/إبطال الجلسة.
- اختبار عزل حساب الشريك وعدم قبول معرف شريك من الشاشة كمصدر هوية.
- اختبار أن قائمة السقايات تعرض جميع العمليات غير الملغاة للمحطة.
- اختبار أن واجهات الشريك للقراءة فقط ولا تنشئ قيودًا أو تعدّل الفواتير.
