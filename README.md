# ساقية لإدارة محطة ضخ مياه الري

مصدر Flutter/Dart مبني من الصفر وفق وثيقة المواصفات التنفيذية المرفقة.

## المكونات
- `lib/`: تطبيق الإدارة والطبقات المحلية والمحاسبة والتقارير والنسخ والإشعارات والمزامنة وAPI client.
- `assets/db/001_initial.sql`: الجداول الأساسية الـ25.
- `server/`: REST API تحت `/api/v1` مع JWT ومسارات الإدارة والمستفيد.
- `test/`: اختبارات الحسابات والصلاحيات.
- `docs_REQUIREMENTS_TRACEABILITY.md`: مصفوفة تتبع المتطلبات.
- `docs_STATUS.md`: حالة التنفيذ والقيود المعروفة.

## قاعدة الاستعادة الجاهزة للـAPK

ملف قاعدة البيانات موجود مباشرةً في جذر المستودع: [`saqia_names_only_apk_restore.db`](./saqia_names_only_apk_restore.db). يحتوي أسماء 50 مستفيدًا و5 شركاء وعامل واحد. بُني على مخطط الإصدار 18، ويمكن للتطبيق الحالي ترقيته عند فتحه. النسخة مضبوطة على نوع منظومة شمسي (`solar`).

## قاعدة اختبار السرعة للهاتف

قاعدة [saqia_speed_test_10k.db](./saqia_speed_test_10k.db) موجودة مباشرةً في جذر المستودع، وحجمها نحو 1.55 ميغابايت. تضم 10,922 صفًا إجمالًا عبر جداول القاعدة، منها 800 مستفيد، و20 شريكًا، و10 عمال، و900 سجل سقاية، و400 دفعة، و120 مصروفًا، إضافةً إلى السجلات المحاسبية والمرتبطة. هي قاعدة اصطناعية على مخطط الإصدار 19 ونوع منظومة شمسي (`solar`)، ويمكن اختيار ملف `.db` مباشرةً للاستعادة دون فك ضغط.

**الاستعادة تستبدل بيانات التطبيق الحالية**؛ أنشئ نسخة احتياطية قبل التجربة.

## قاعدة اختبار ضخمة

أرشيف قاعدة البيانات المضغوط [saqia_massive_test_data.db.zip](./saqia_massive_test_data.db.zip) موجود في جذر المستودع وحجمه نحو 8.5 ميغابايت، أي أقل من 20 ميغابايت. يحتوي ملف SQLite كاملًا حجمه بعد فك الضغط نحو 58.8 ميغابايت، ومبنيًا على مخطط التطبيق الحالي الإصدار 19. يضم بيانات اصطناعية فقط: 20,000 مستفيد، و200 شريك، و80 عاملًا، و50,000 سجل سقاية، و25,000 دفعة، و5,000 مصروف، إضافةً إلى سجلات محاسبية واختبارية أخرى. لا يحتوي أسماء أو أرقام هواتف حقيقية.

لاستعادتها، نزّل ملف ZIP وفك ضغطه أولًا للحصول على `saqia_massive_test_data.db`، ثم اختر ملف `.db` من خيار النسخ الاحتياطي والاستعادة في التطبيق؛ التطبيق لا يستورد ZIP مباشرةً. نوع المنظومة شمسي (`solar`). **استعادة قاعدة البيانات تستبدل بيانات التطبيق الحالية**؛ أنشئ نسخة احتياطية من بياناتك قبل التجربة.

## التشغيل
يتطلب Flutter/Dart SDK. بعد توفر البيئة:

```text
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
flutter build apk --release
flutter build web
```

لا تعتبر نتيجة البناء ناجحة إلا إذا نفذت الأوامر فعليًا ونجحت.

## قاعدة مهمة
القيم المالية تحفظ كأعداد صحيحة بوحدة أصغر للعملة، ولا تستخدم Float للحساب المالي. العمليات المركبة تستخدم DB transactions، والقيود المحاسبية ترفض إذا لم يتساوَ المدين والدائن.

## تدقيق المطابقة
المصدر يضم طبقات الإدارة والمستفيد وREST API والمحاسبة المحلية والتقارير والنسخ والمزامنة. الاختبار التنفيذي النهائي يتطلب Flutter/Dart SDK، ولا يُعد البناء ناجحًا قبل تشغيل analyze/test/build فعليًا.
